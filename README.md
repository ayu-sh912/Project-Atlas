# ATLAS

## A Topographically Legit Assistance System

ATLAS is a campus-specific pedestrian navigation platform designed to provide accurate navigation and contextual information within a university campus.

### Core Components

- Frontend Interface
- Backend API
- Campus Data Layer
- Graph-Based Routing Engine
- Dijkstra Algorithm
- A* Algorithm
